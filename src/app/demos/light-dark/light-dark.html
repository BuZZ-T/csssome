LightDark

Use light-dark() to define colors that adapt to the active color scheme without extra theme classes. 

:root {
  color-scheme: light dark;
}

.card {
  background: light-dark(#f7f8fc, #171722);
  color: light-dark(#19212d, #f5f7fb);
}
