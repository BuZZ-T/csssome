Scroll State

Use @container scroll-state(stuck: ...) to style a sticky element while it is actually pinned to an edge. The sticky element becomes a container-type: scroll-state container, and a child reacts to the state — no JavaScript scroll listeners needed.

@for (edge of edges; track edge) { } 
.sticky {
  position: sticky;
  {{ selectedEdge() }}: 0;
  container-type: scroll-state;
}

.sticky > .inner {
  @container scroll-state(stuck: {{ selectedEdge() }}) {
    background: #7c6af7;
  }
}
