Container Queries

Use container-name on a parent, then target it with @container so components adapt to their own space instead of the viewport. 

.panel {
  container-name: feature-panel;
  container-type: inline-size;
}

@container feature-panel (min-width: 520px) {
  .card {
    grid-template-columns: 92px 1fr;
  }
}
