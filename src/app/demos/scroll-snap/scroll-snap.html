Scroll Snap

Use scroll-snap-type on a container and scroll-snap-align on children to create buttery smooth snapping scroll experiences — no JavaScript needed. 

.container {
  overflow-y: scroll;
  scroll-snap-type: y mandatory;
}

.slide {
  scroll-snap-align: start;
  scroll-snap-stop: always;
}
