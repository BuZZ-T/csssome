ShapeOutside

Use shape-outside: url(...) with shape-margin to wrap text around a transparent image. 

.float {
  shape-outside: url('/images/shape-outside.svg');
  shape-margin: 1rem;
}

.photo {
  -webkit-mask-image: url('/images/shape-outside.svg');
  mask-image: url('/images/shape-outside.svg');
}
