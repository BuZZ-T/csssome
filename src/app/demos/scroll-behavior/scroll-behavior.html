Scroll Behavior

Use scroll-behavior to control whether programmatic scrolling (e.g. anchor links, scrollIntoView()) happens instantly or is animated smoothly.

.scroll-area {
  scroll-behavior: {{ selectedMode().id }};
}

Section 1

Instant vs. smooth

Click one of the buttons above to jump to a section further down this scroll container. With auto the jump is instant; with smooth the browser animates the scroll.

Section 2

scrollIntoView()

The navigation buttons call element.scrollIntoView(), which respects the scroll-behavior of its scrolling container instead of needing an explicit { behavior: 'smooth' } option.

Section 3

Anchor links

The same effect applies to in-page anchor links (<a href="#id">) and to scrolling triggered by the keyboard, without any JavaScript at all.

Section 4

The last section

You made it! Try switching back to auto above and jumping between sections again to feel the difference.

  • scroll-behavior only affects scrolls triggered programmatically or via anchor navigation — it does not change manual scrolling with the mouse wheel, trackpad or touch.
  • It can be set on any scroll container, not just html/body — here it's set on the scrollable area itself.
