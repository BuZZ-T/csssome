Clamp

Use clamp(min, preferred, max) to size elements fluidly between a lower and an upper bound. It replaces whole stacks of media queries with a single declaration.

This box uses {{ selectedMode().property }}: {{ selectedMode().value }}. Switch the container width above (or resize the window) and watch it adapt — without a single @media rule.

  • clamp(MIN, VAL, MAX) is shorthand for max(MIN, min(VAL, MAX)) — the preferred value is used as long as it stays inside the bounds.
  • The preferred value is usually a relative unit such as %, vw or a calc() expression, which is what makes the result fluid.
  • Because it's a plain value function, clamp() works for any length, angle, time or number property — not just width.
