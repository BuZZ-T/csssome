# csssome

**csssome** — not only awesome, but csssome. An Angular single-page application that showcases modern CSS features with interactive, hands-on demos. Each feature gets its own page with a live example you can play with, the CSS behind it, and a browser support table that also tells you whether your current browser supports it. Pick a feature from the navigation on the left to try it out.

Live demo: https://buzz-t.github.io/cssssome

## Features

- **Animation Timeline** — scroll- and view-driven animation examples using `animation-timeline`.
- **Aspect Ratio** — layout cards demonstrating practical `aspect-ratio` values.
- **Base Select** — native `<select>` styling with `appearance: base-select`.
- **Clamp** — fluid sizing without media queries using `clamp()`.
- **Container Queries** — a responsive panel using `container-name` and `@container`.
- **Content Visibility** — skip rendering work for offscreen content with `content-visibility`.
- **Contrast Color** — automatically readable foreground colors using `contrast-color()`.
- **Corner Shape** — rounded, squircle, bevel and scoop corners using `corner-shape`.
- **Font Variant Numeric** — interactive samples for `font-variant-numeric` values.
- **Highlight** — style arbitrary text ranges with `::highlight()` and the CSS Custom Highlight API.
- **Hyphens** — manual (`&shy;`) and automatic line breaking with `hyphens`.
- **Light Dark** — theme-aware color examples using `light-dark()`.
- **Paint Order** — control whether fill or stroke is painted first with `paint-order`.
- **Progress** — map a value between two bounds to a 0–1 ratio using `progress()`.
- **Scroll Behavior** — smooth versus instant scrolling with `scroll-behavior`.
- **Scroll Snap** — snap-scrolling demo with `scroll-snap-type`.
- **Scroll State** — respond to sticky positioning state using `@container scroll-state()`.
- **Shape Outside** — wrapped text around a transparent image using `shape-outside`.
- **View Transition** — CSS-only cross-document transitions using `@view-transition`, `::view-transition-old` and `::view-transition-new` (no JavaScript).
