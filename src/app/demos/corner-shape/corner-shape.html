Corner Shape

Use corner-shape together with border-radius to change what kind of curve fills a rounded corner — from classic circular arcs to concave scoops, bevels, notches and superellipse-based squircles.

  • corner-shape only takes effect where border-radius is non-zero — it changes the curve used to fill the rounded corner, it doesn't create rounding on its own.
  • Every named keyword (round, scoop, bevel, notch, square, squircle) is really just a shorthand for a specific superellipse() exponent.
  • Like border-radius, the four corners can be set independently with the longhands corner-top-left-shape, corner-top-right-shape, corner-bottom-right-shape and corner-bottom-left-shape.
