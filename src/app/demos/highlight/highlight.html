Highlight

The ::highlight() pseudo-element styles arbitrary text ranges registered with the CSS Custom Highlight API (CSS.highlights) — without wrapping the text in any extra markup like <mark> or <span>.

@for (term of terms; track term.id) { } 
const range = new Range();
range.setStart(textNode, start);
range.setEnd(textNode, end);

CSS.highlights.set(
  'demo-highlight-keyword',
  new Highlight(range)
);
::highlight(demo-highlight-keyword) {
  color: #fff;
  background-color: #7c6af7;
}

::highlight(demo-highlight-warning) {
  color: #1a1a1a;
  background-color: #f7c948;
}

::highlight(demo-highlight-success) {
  color: #0a2e1c;
  background-color: #4ad991;
}

Choose a word group above, then look at the paragraph below: the matching words are highlighted purely via CSS, even though there is no <mark> element anywhere in the DOM. JavaScript only finds the text ranges and registers them — every visual change (color, background) is applied by the ::highlight() rule.

The CSS Custom Highlight API lets you style text ranges without any extra markup. You create Range objects, add them to a Highlight, and register it on CSS.highlights under a name. The browser then paints those ranges using the ::highlight() pseudo-element, matched by that same name. Because the highlighting is applied via JavaScript and CSS, you can restyle it instantly, and the same ranges can be reused for search results, spell-check hints, or collaborative editing cursors.

  • ::highlight() only supports a limited set of properties: color, background-color, text-decoration, and a few others — no display or box-model changes.
  • Multiple named highlights can be active at once, and they stack in the order they were registered on CSS.highlights.
  • Because ranges are plain DOM Range objects, highlights can even span across multiple elements.
