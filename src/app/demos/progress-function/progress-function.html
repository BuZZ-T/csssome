Progress

progress() is a CSS math function that computes how far a value sits between a start and an end point, returning a number between 0 and 1 (and beyond, if the value overshoots). It turns "map this value onto a 0–1 range" from a JavaScript one-liner into pure CSS.

@for (range of ranges; track range.id) { } 
.bar-fill {
  width: calc(100% * progress(
    {{ value() }},
    {{ selectedRange().start }},
    {{ selectedRange().end }}
  ));
}

Drag the slider to change the value. The bar width, its label and its color are all driven purely by progress() — no JavaScript recalculates the percentage.

  • progress(value, start, end) returns (value - start) / (end - start) as a plain number, so it can be multiplied into any length, percentage or angle with calc().
  • Values outside the [start, end] range aren't clamped — the result can go below 0 or above 1, which is useful for overshoot effects.
  • It complements clamp() and container queries as part of CSS's growing set of math functions for responsive design without JavaScript.
  • All three arguments must share the same unit (or all be unitless) — that's why the temperature example uses plain numbers rather than °C, which isn't a real CSS unit and would make the whole expression invalid.
