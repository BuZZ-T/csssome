Contrast Color

contrast-color() picks black or white for you — whichever gives better contrast against a given background color. No more manually computing luminance to decide if text should be light or dark.

@for (swatch of swatches; track swatch.id) { } 
.card {
  background: {{ selectedSwatch().value }};
  color: contrast-color({{ selectedSwatch().value }});
}

  • contrast-color() only ever returns pure black or white — it's a simple, fast heuristic, not a full WCAG contrast calculation with arbitrary target colors.
  • It's most useful for labels, icons or text placed on dynamically-generated or user-supplied background colors, where you can't know the color ahead of time.
  • Unlike light-dark(), it doesn't depend on color-scheme or user preference — it purely reacts to the background color you pass in.
