Content Visibility

Use content-visibility to let the browser skip rendering work for off-screen content. auto defers layout and paint until the element is near the viewport, which can massively speed up pages with long lists of content.

@for (mode of modes; track mode.id) { } 
.card {
  content-visibility: {{ selectedMode().id }};
  contain-intrinsic-size: 0 220px;
}

{{ selectedMode().description }}

Scroll the list below. Open your browser's dev tools “Rendering” panel and enable “Layout Shift Regions” / paint flashing to see that off-screen cards are skipped when auto or hidden is selected.

Card #{{ item }}

Section {{ item }}

This card's rendering is controlled by content-visibility: {{ selectedMode().id }}. When set to auto, the browser skips layout and paint while it is off-screen and restores it automatically as it scrolls into view. When set to hidden, the content stays skipped even when scrolled into view, but its internal render state is preserved for a cheap re-render later.

}
  • contain-intrinsic-size reserves space for skipped content so the page doesn't jump around as elements enter and leave the rendering subtree.
  • content-visibility: hidden behaves like display: none for rendering purposes, but unlike display: none it keeps any cached render state, so toggling it back to visible is cheaper than rendering from scratch.
  • Try switching to hidden above — the cards below collapse to their reserved intrinsic size and their content is no longer rendered.
