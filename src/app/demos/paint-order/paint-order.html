Paint Order

paint-order controls the order in which the fill and stroke of an SVG shape or text are painted. It's most visible with a thick stroke, which by default is painted on top of the fill and can hide it — reordering lets the fill sit on top instead.

@for (value of values; track value.id) { } 
text, .shape {
  paint-order: {{ selectedValue().id }};
  fill: #ffd166;
  stroke: #4d3fc0;
  stroke-width: 8px;
}

{{ selectedValue().description }}

@for (value of values; track value.id) {
{{ value.label }}
}
  • Painting order only matters when fill and stroke visually overlap — that's why a wide stroke-width is used here to make the effect obvious.
  • paint-order applies to any SVG shape or text element, not just <text> — it works the same way on <path>, <circle> and other shapes with both a fill and a stroke.
  • Any keyword you omit is simply appended afterwards in its default relative order, so paint-order: stroke is shorthand for stroke fill (plus markers, which has no effect outside SVG's own marker elements).
